# Hey, I'm Strugglehugs.

I'm a software engineer with roots in .NET. My public projects explore developer tools, agent workflows, and self-hosted games, mostly in TypeScript and Python.

I like turning messy workflows into tools people can inspect, run, and improve.

## What I'm building

- **[SlopLens](https://github.com/Stormxftw/SlopLens)** — A local dashboard for reviewing Codex and Claude Code projects, activity, and unfinished work.
- **[H.Realms](https://github.com/Stormxftw/H.Realms)** — A Linux-first console for managing local game servers through Hermes, with reviewed operations, backups, and diagnostics. Currently an MVP / pre-release.
- **[HermesStuff](https://github.com/Stormxftw/HermesStuff)** — Reusable Hermes Agent skills, starting with an evidence-focused workflow for investigating suspicious Linux activity.

## Where I'd like to contribute

Developer experience, practical agent tooling, and game-server infrastructure. I'm here to share what I build, contribute useful fixes, and learn from other maintainers.

## Feedback welcome

Tried one of my projects? Open an issue in its repository with what you expected, what happened, and how to reproduce it. Clear bug reports and honest feedback help me make the next release better.
